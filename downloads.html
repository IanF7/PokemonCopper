Download Instructions

Windows

1. Download the latest version of Pokémon Copper.

2. Extract the Pokémon Copper files.

3. Run the Game.exe file.

Mac

1. Download Porting Kit from the Porting Kit download page.

2. Download the latest version of Pokémon Copper.

3. Extract the Pokémon Copper files.

4. Open Porting Kit and choose "Install".

5. When asked for the Windows program, go to the folder where you extracted the Pokémon Copper files and select Game.exe

6. Finish the setup and launch the game from Porting Kit.

Linux

1. Download and install the latest version of Wine for your Linux build from the Wine download page.

2. Download the latest version of Pokémon Copper.

3. Extract the Pokémon Copper files.

4. Open the terminal in the file path that the Pokémon Copper "Game.exe" file is located.

5. In the terminal, run: wine Game.exe

Android

1. On your Android device go to the JoiPlay Patreon page and download JoiPlay 1.21.000 and RPG Maker Plugin 1.22.00.

2. Download the latest version of Pokémon Copper.

3. Go to your Downloads folder and run the JoiPlay download and then the RPG Maker Plugin. Make sure to allow all permissions.

4. Extract the Pokémon Copper file.

5. Open JoiPlay and click the + button and then Add Game. Navigate to the path of Pokémon Copper and add it.

6. Run the game from JoiPlay.

Steam Deck

1. Switch Steam Deck to desktop mode.

2. Download the latest version of Pokémon Copper.

4. Extract the Pokémon Copper file.

5. Right click Game.exe and select "Add to Steam".

6. Still in desktop mode, open Steam and find Game.exe in your library.

7. Right click on Game.exe, select "Properties", and rename to Pokémon Copper.

7. Switch back to game mode and run.

Update Instructions

Windows, Linux, Mac, and Steam Deck

1. Download the latest version of Pokémon Copper.

2. Delete the old version of Pokémon Copper. Don't worry, you save data is saved in a different location so it won't be erased.

3. Extract the new verion.

Android

1. Download the latest version of Pokémon Copper.

2. Extract the new version.

3. Open the file for the OLD version and find a file called something like "File A.rxdata" (the letter may vary depending on which save slot you saved your data in). This will be in the same filepath as Game.exe.

4. Hold down on the "File A.rxdata" folder and select Copy. When it asks where you want to copy it to, navigate to the NEW version, and once you are in the same file directory as the NEW verison's Game.exe file, select Copy Here.

5. Delete the OLD version of the game and add the NEW version to JoiPlay.
