Download Instructions (Game and Launcher Not Installed)

Windows, Mac, Linux, and Steam Deck

1. Download the full game and unzip it.

2. Open Launcher.exe in the Pokemon Copper folder.

3. Mac, Linux, and Steam Deck users: follow the additional setup instructions for your platform below.

4. Click Install and then Play.

Mac

1. Download Porting Kit from the Porting Kit download page.

2. Open Porting Kit and choose "Install".

3. When asked for the Windows program, go to the folder where you extracted the Pokémon Copper files and select Launcher.exe.

4. Finish the setup and open the launcher from Porting Kit.

Linux

1. Download and install the latest version of Wine for your Linux build from the Wine download page.

2. Open the terminal in the folder where the Pokémon Copper Launcher.exe file is located.

3. In the terminal, run: wine Launcher.exe

Steam Deck

1. Switch Steam Deck to desktop mode.

2. Right click Launcher.exe and select "Add to Steam".

3. Still in desktop mode, open Steam and find Launcher.exe in your library.

4. Right click on Launcher.exe, select "Properties", and rename it to Pokémon Copper.

5. Switch back to game mode and run.

Android

1. On your Android device go to the JoiPlay Patreon page and download JoiPlay 1.21.000 and RPG Maker Plugin 1.22.00.

2. Download the latest version of Pokémon Copper for Android.

3. Go to your Downloads folder and run the JoiPlay download and then the RPG Maker Plugin. Make sure to allow all permissions.

4. Extract the Pokémon Copper file.

5. Open JoiPlay and click the + button and then Add Game. Navigate to the path of Pokémon Copper and add it.

6. Run the game from JoiPlay.

Download Instructions (Game Installed but not Launcher)

Windows, Mac, Linux, and Steam Deck

1. Download Launcher.exe.

2. Find your Pokemon Copper folder and drag Launcher.exe into it. It should be in the same folder as Game.exe.

3. If you are on Mac, Linux, or Steam Deck, follow the steps in the Download Instructions to point everything to Launcher.exe instead of Game.exe, if you haven't done so already.

4. Open Launcher.exe. The first time it opens, it will check your game files to make sure you are up to date. This may take a few minutes. It will then download any new files it needs.

5. Click Play.

From then on, just open Launcher.exe and it will update the game for you.

Android

The launcher doesn't run on Android, so updating still has to be done manually:

1. Download Pokemon-Copper-Android.zip and extract it.

2. Open the folder for the OLD version and find a file called something like "File A.rxdata" (the letter may vary depending on which save slot you saved your data in). This will be in the same folder as Game.exe.

3. Hold down on the "File A.rxdata" file and select Copy. When it asks where you want to copy it to, navigate to the NEW version, and once you are in the same folder as the NEW version's Game.exe file, select Copy Here.

4. Delete the OLD version of the game and add the NEW version to JoiPlay.
